1 Overview

In this exercise, we use methods like Hierarchical Cluster Analysis (HCA) and Spatially Constrained Cluster Analysis (SCCA) including (SKATER and ClusGeo) to group neighbouring spatial units into homogeneous regions (areas that are similar to each other in terms of variables, i.e. geographically referenced multivariate).

1.1 Learning Outcome

The tasks to be completed are to:

  • convert simple feature data.frame into R’s SpatialPolygonDataFrame object using as_Spatial() of sf package

  • perform cluster analysis with hclust() of Base R

  • perform spatially constrained cluster analysis using skater() of Base R

  • visualise the analysis using ggplot2 and tmap package.

2 Getting Started

2.1 The Analytical Question

In real world application likes geobusiness and geospatail related policy making, regions are defined by statistical similarity in the multivariate data. In the case study of Shan State Myanmar, we find and outline the clusters of areas that share similar characteristics, through multiple Information and Communication technology (ICT) measures, namely: Radio, Television, Land line phone, Mobile phone, Computer, and Internet at home.

4.3 Derive Bew Variables Using dplyr Package

The code chunk below derives the penetration rate of each ICT variable based on total household number in township. We should always transform absolute values to relative measures before doing spatial analysis or clustering, otherwise the results will be dominated by township size.

  mutate(`RADIO_PR` = `Radio`/`Total households`*1000) %>%
  mutate(`TV_PR` = `Television`/`Total households`*1000) %>%
  mutate(`LLPHONE_PR` = `Land line phone`/`Total households`*1000) %>%
  mutate(`MPHONE_PR` = `Mobile phone`/`Total households`*1000) %>%
  mutate(`COMPUTER_PR` = `Computer`/`Total households`*1000) %>%
  mutate(`INTERNET_PR` = `Internet at home`/`Total households`*1000) %>%
  rename(`DT_PCODE` =`District Pcode`,`DT`=`District Name`,

         `RADIO`=`Radio`, `TV`=`Television`, 
         `LLPHONE`=`Land line phone`, `MPHONE`=`Mobile phone`,
         `COMPUTER`=`Computer`, `INTERNET`=`Internet at home`)

cluster_vars.cor = cor(ict_derived[,12:17]) #corr matrix

7 Hiearachy Cluster Anlaysis

The general workflow of hierarchy cluster analysis consists of:

  1. Extracting clustering variables (screen for NAs & high correlations). st_set_geometry(NULL); select(); row.names()

  2. Standardising the variables (min-max/ z-scores). normalize(); scale()

  3. Computing a proximity (distance) matrix (often Euclidean). dist()

  4. Running hierarchical clustering (choose linkage, e.g., ward.D2). hclust();agnes()

  5. Determining the optimal number of clusters (dendrogram + silhouette/gap/NbClust). clusGap(FUN = hcut)

  6. Interpreting the dendrogram & profile clusters (cluster means, maps, tables).rect.hclust()

  7. Visualisation (dendrogram, heatmap, spatial choropleths). heatmaply(), cutree(), cbind(), qtm()

7.6 Determining Optimal Clusters

Another technical challenge is deciding on the optimal number of clusters to retain. Choosing too few clusters may oversimplify the data, while too many clusters may lead to overfitting and poor interpretability.

Three commonly used methods to determine the appropriate number of clusters are:

Elbow Method

  • Plots the total within-cluster sum of squares (WSS) against the number of clusters.

  • The “elbow” point, where the rate of decrease sharply slows, indicates a suitable number of clusters.

Average Silhouette Method

  • Computes the silhouette coefficient, which measures how similar an observation is to its own cluster compared to other clusters.

  • The number of clusters with the highest average silhouette value is considered optimal.

Gap Statistic Method

  • Compares the total within-cluster variation for k different numbers of clusters with the expected values under a null reference distribution.

  • The optimal number of clusters is the one that maximises the gap statistic.

7.7 Interpreting the Dendrograms

In the dendrogram, each leaf represents an observation. Moving upward, similar observations are joined into branches, which then merge at higher levels. The vertical axis shows the fusion height, reflecting dissimilarity: lower values indicate greater similarity, while higher values mean less similarity. Similarity can only be inferred from the height at which branches first merge, not from their horizontal positions.

9 Spatially Constrained Clustering: ClustGeo Method

In this section, we perform non-spatially constrained hierarchical cluster analysis and spatially constrained cluster analysis with ClustGeo package.

9.1 A short note about ClustGeo package

ClustGeo is an R package for spatially constrained clustering.

It implements a Ward-like (variance-minimising) hierarchical method, hclustgeo(), that blends two dissimilarities:

  • D0: a dist object represents dissimilarity in the attribute space (can be non-Euclidean; observations may be weighted).

  • D1: a dist object represents dissimilarity in the spatial/constraint space.

A mixing parameter alpha (0,1) controls the trade-off via a convex combination of homogeneity criteria:

criterion= (1-a) * crit(D0) + a * crit*(D1)

The goal is to choose alpha to increase spatial contiguity without unduly harming cluster quality on the variables of interest. The function choicealpha() estimates a suitable alpha by comparing solutions across alpha values.

Note

hclustgeo(D0, D1 = NULL, alpha = 0, scale = TRUE, wt = NULL)

  • hclustgeo(D0) = non-spatial (standard Ward).

  • hclustgeo(D0, D1, alpha) = spatially constrained clustering.

  • Scale is used when both D0 and D1 are included, and scaled by i.e. divided by their max.

9.2 Ward-like hierarchical clustering: ClustGeo

hclustgeo() extends the base R function hclust(). Under the hood, it constructs a dendrogram object with the same structure as stats::hclust.
